
# Student Management & Attendance System

A console-based Java application for managing student information and attendance efficiently. The system provides features to add, remove, update, search, sort, and filter student records along with attendance tracking and report generation.

## 🚀 Key Features

* Add new student records
* View complete student details
* Search students by Name or ID
* Update student information
* Remove student records
* Sort students alphabetically by name
* Filter students by course
* Mark student attendance
* View attendance records
* Calculate attendance percentage
* Generate student and attendance reports
* Simple menu-driven console interface

## 🛠️ Technologies Used

* Java
* Java Collections & Arrays
* Object-Oriented Programming (OOP)
* String & StringBuffer
* Scanner for User Input
* File-free Console-Based Application
